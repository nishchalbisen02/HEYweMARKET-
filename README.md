# Hey We Market

Marketing site for **Hey We Market** — an independent 360° digital marketing agency
(SEO &amp; AEO, Google &amp; Meta Ads, Google Business Profile, content, social, commercial
shoots, branding and web).

## Stack

- **Next.js 16** (App Router, Turbopack) · **React 19** · **TypeScript**
- **Tailwind CSS v4** · **shadcn/ui** (`components.json`, Base UI primitives)
- **motion** + **lenis** for the cinematic scroll hero
- Neubrutalist design system generated by [`ui-ux-pro-max`](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill):
  hot-pink `#EC4899` / cyan `#0891B2` palette, hard 3px borders, hard offset shadows,
  0px radius, Archivo / Space Grotesk / Space Mono.

## Develop

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

```bash
npm run build   # production build
npm run start   # serve the production build
```

## Structure

| Path | What |
|---|---|
| `src/app/layout.tsx` | fonts, metadata, JSON-LD (Organization + WebSite + FAQPage), header/footer/FABs |
| `src/app/page.tsx` | the one-page site — all chapters composed |
| `src/app/globals.css` | Tailwind v4 theme + brutalist tokens |
| `src/components/cinematic-hero.tsx` | scroll-driven hero — image scale, parallax, SVG mask reveal, play button (a from-scratch rebuild of the paid `@skiper-ui/skiper29` effect using MIT-licensed `motion` + `lenis`) |
| `src/components/growth-audit.tsx` | interactive 360° Growth Audit — 12 questions → scored report + two downloadable HTML/PDF reports, all client-side |
| `src/lib/site.ts` · `src/lib/audit.ts` | content + audit data / scoring / report generators |
| `legacy/index.html` | the previous single-file static build, kept for reference |

## Deploy

Deploy to **Vercel** (`vercel`) or any Node host that runs `next build` + `next start`.
It is no longer a single static file — it needs a build step.

## Skiper UI (optional)

`skiper29` and the other `@skiper-ui/*` components are **paid (Skiper UI Pro)**. To use the
real component instead of the rebuild, add your license key to `.env.local`, register the
registry in `components.json`, then `npx shadcn add @skiper-ui/skiper29`.
